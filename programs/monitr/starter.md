# Стартер МОНИТР: том 4001, зона 0001

[starter.be](starter.be) — дизассемблирование в **БЕМШ**, с именами меток
по назначению ячеек и комментариями. [starter.sym](starter.sym) задаёт
адреса и разделение кода и данных для `disbesm6`.

Зона загружается в `00000–01777`. Команд **ПВ нет**, включая весь код
обработчиков; проверка сырых полуслов всей зоны также не обнаружила кода
операции `31`. Поэтому условие выбора БЕМШ выполнено. Вызовы ОС — экстракоды.

Исходник начинается с `СТАРТ 1`; все метки не длиннее шести символов.
Последнее ненулевое слово находится по адресу `00175`, за ним сразу `ФИНИШ`.
Завершающего `ПАМ` нет. При записи зоны сохраняются все 1024 слова, включая
нулевую ячейку `00000` и нулевой хвост.
Код занимает 42 слова, включая заполнители правых половин; его интервалы:

```text
00001–00002, 00004, 00010, 00075–00126, 00132–00136, 00143–00151
```

В остальных словах находятся данные и резервы. Нулевые области записаны
директивами `ПАМ`; их размеры в исходнике десятичные. Адреса ниже восьмеричные.
Обратная сборка БЕМШ выполнена без ошибок; **все 1024 слова записанной зоны
совпадают с зоной `0001` тома `4001`**. Стартер при сборке не запускается.

## Пакет сборки и сравнения

Из корня репозитория:

```sh
python3 programs/monitr/build-starter.py
```

[build-starter.py](build-starter.py) создаёт и исполняет пакет БЕМШ/ДВС:
`ВВД$$$`, `ТРН$$$`, загрузка компоновщика `ЧТКОМП420070`, `НАЗ 000001`,
**`ЗОНГП 430001 000001`**. Затем `besmtool` извлекает зону `0001` частного
тома `1234` и исходного тома `4001`; сравниваются все 1024 слова без масок
или исправлений. При различиях пакет завершается с ошибкой и выводит адреса
и восьмеричные значения слов. Исходный том `4001` проверяется на неизменность.

Нужны `dispak`, `besmtool` и исходные тома `2048`, `2099`, `4001` на
`BESM6_PATH` (по умолчанию `~/.besm6:/usr/local/share/besm6`).
Запись идёт только на частный том `runtime/build/monitr-starter/1234`.
Повторный запуск пересоздаёт этот частный том.

Артефакты в `runtime/build/monitr-starter/`:

- `starter.b6` — сформированный пакет с текстом `starter.be`;
- `starter.lst` — листинг ассемблера и компоновщика;
- `starter.img` — зона, полученная командой `ЗОНГП`;
- `zone1.bin` — исходная зона `4001/0001`;
- `comparison.txt` — результат сравнения и различия, если они есть.

## Точки входа

| Адрес | Метка | Назначение |
|---|---|---|
| `00001` | `ЗАПУСК` | Чтение первой зоны программы по адресу из A и переход на `02000` |
| `00002` | `ВОЗВР` | Перезапуск интерпретатора с инициализацией SYSLIB |
| `00004` | `ВЫХОД` | Завершение работы через `00133` |
| `00010` | `НАЧАЛО` | Установка РЖ=7, опрос терминалов и вывод заставки |
| `00105` | `ПЕРЕП` | Установка реакций на авост и завершение, инициализация SYSLIB |
| `00114` | `АВОСТ` | Получение кода и текста ошибки, вывод, проверка `ФЛАГ` |
| `00132` | `КОНЕЦ` | Реакция на завершение задания: `ПБ ПЕРЕП` |
| `00133` | `ВЫЙТИ` | `Э62 44` при наличии терминала, снятие перехвата авоста, `Э62 0` |
| `00143` | `ЧТПАСК` | Отключение асинхронных событий и чтение зоны в `02000` |

При A = ISO `KEYE72` аргумент `Э72` — адрес обработчика. Поэтому
`Э72 КОНЕЦ` устанавливает обработчик по адресу `00132`; при завершении
выполняется находящийся там `ПБ ПЕРЕП`. Восстановлен и обработчик `00114`,
который нельзя найти только по непосредственным переходам: его адрес
передаётся через A в `Э50 103`.

## Общие ячейки

| Адреса | Содержимое |
|---|---|
| `00003` | Активная библиотека, первоначально ISO `SYSLIB` |

| `00006` | Ненормализованная единица с целым порядком `6400000000000001` |

| `00053` | Адрес буфера каталога `76000` |

| `00055–00072` | Командная строка, 84 символа в 14 словах |
| `00073` | Имя запускаемой программы, первоначально ISO `SYSLIB` |
| `00074` | Флаг программы, проверяемый обработчиком авоста |
| `00127–00131` | Буфер описания ошибки, 18 символов |
| `00141–00142` | Управляющие слова терминального вывода |
| `00152–00161` | Заставка в ГОСТ |
| `00162` | Конец текста: байт `377` в старшем байте слова |
| `00163–00164` | Управляющие слова печати |
| `00165–00166` | Сырые целые 1 и 2 |
| `00167` | ISO `KEYE72`: аргумент `Э72` задаёт адрес обработчика |
| `00170` | Шаблон чтения зоны `0010010000000000` |
| `00172` | Рабочее управляющее слово `Э70` |
| `00175` | Начальный адрес Pascal: устройство `030`, зона `0002` |
| `00176–01777` | Нулевой хвост, 898 слов |

Заставка расшифровывается как:

```text
****----МОНИТОР ВЕРС.01 ОТ 02.11.89----****
```

Это дата версии в тексте, а не независимо установленная дата записи зоны.

## Передача управления Pascal

`ЧТПАСК` оставляет в A младшие 15 бит адреса и объединяет их с шаблоном
`0010010000000000`. Через `Э70` читается **одна** зона в `02000`; затем A
снова получает управляющее слово, М15 — адрес возврата `00105`, и выполняется
`ПБ 02000`. Первой зоной интерпретатора является `0002`; остальные зоны
дочитывает его PASCODER-заголовок. Интерпретатор описан в [README.md](README.md).

При перезапуске пара `00021–00022` получает имя `SYSLIB` и адрес `0300000`:
это `ПАСАДР XOR 2`, то есть то же устройство, зона каталога `0000`.
Повторный `НТЖ 2` восстанавливает адрес образа `0300002` в A.

## Повторное извлечение

Из корня репозитория, с исходным томом 4001 на `BESM6_PATH`:

```sh
mkdir -p runtime/build/monitr-starter
besmtool dump 4001 --start=01 --length=1 \
  --to-file=runtime/build/monitr-starter/zone1.bin
./disbesm6 -b -s -a0 -e1 -e2 -e4 -e10 -e114 -e132 \
  -n programs/monitr/starter.sym \
  runtime/build/monitr-starter/zone1.bin
```

`disbesm6` пропускает аппаратную нулевую ячейку и выдаёт `СТАРТ '1'`.
В сохранённом `starter.be` метки сокращены до шести символов, убран
завершающий резерв; управляющие слова вывода представлены данными,
добавлены комментарии.
Бинарный экстракт и промежуточные листинги остаются в каталоге сборки.
