# dispak-tools
Various tools for OS DISPAK for BESM-6, disassembled/decompiled.

## Pascal runtime recovery

[runtime/README.md](runtime/README.md) describes the Pascal image corpus extracted
from volume 4001, its analysis, and four recovered Madlen runtime libraries.
Compile and run a new program with `python3 runtime/build.py run program.pas`;
use `python3 runtime/build.py check` for the word comparisons and emulator checks.

## MARK3
Утилита для разметки лент ЕС ЭВМ на СВС (Э1-К2) путем прямого доступа к ПВВ.
Для компиляции требуется улучшенный Паскаль-компилятор.

## Паскаль-компилятор

### По сравнению с базовой версией компилятора в составе МС "Дубна" или "Монитор-80", внесены следующие изменения, повторяющие изменения в компиляторе, использовавшемся для разработки кросс-системы программирования Э1-КБ:

 - неиспользуемые байты в строковых константах - нулевые (а не пробелы в коде ISO).
 - исправлена ошибка, вызывающая добавление лишнего слова, если длина строковой константы кратна 6 байтам.
 - избегается избыточная команда чтения сразу после записи (исключая, разумеется, магазинную запись) по тому же адресу
   в том же линейном участке.
 - опция `(*=O-*)` отключает предыдущий пункт: чтение после записи сохраняется, как в программах, оттранслированных
   исходным компилятором (например, COMP с тома 4001, см. `comp.pas`). По умолчанию `(*=O+*)`.
 - реализована конструкция `besm(константа : L-выражение)`, позволяющая ссылаться на переменные и элементы массивов или структур во вставках машинного кода. Например, оператор
   `besm(0 : L-выражение);` эквивалентен оператору `L-выражение := ;` (присваивание сумматора).
 - реализовано номинальное преобразование типов R-выражений с помощью конструкции `тип(выражение)`. Первоначальный тип выражения должен быть однословным.
 - реализовано указание абсолютных адресов для переменных с помощью конструкции `var переменная [ адрес ] : тип;` 
   Адреса обычных переменных в верхнем банке `74000B–77777B` кодируются как абсолютные,
   без ошибочной ссылки на таблицу внешних символов; внешние файлы сохраняют свою адресацию.
 - в `besm` можно записывать несколько машинных команд через запятую, например `besm(100000B : x, 150000B : y, 0 : z);`.
 - код для инициализации переменных типа файл главной программы вставляется не в самое начало объектного модуля, а непосредственно перед началом главной программы.
 - строковые константы, обрамленные двойными кавычками, всегда записываются в кодировке КОИ-8 (как при `(*=A4*)`), независимо от режима `A`.
   Внутри такой константы апостроф – обычный символ, а двойная кавычка удваивается.
 - соглашение о связях внешних процедур `ASSEMBLER` (`procedure p(...); assembler;`): все фактические параметры,
   кроме последнего, засылаются в магазин; последний остается на сумматоре
   (однословные параметры-значения – значением, остальные – адресом), без заголовка
   кадра; вызов – `пв p(13)`. Процедура сама снимает параметры с магазина и возвращается
   по `13, uj,`; результат функции – на сумматоре. Процедура снимает с магазина `n-1` параметров,
   сохраняет регистры 1–7; регистр 8 восстанавливает вызывающий код. Поэтому, как и после вызова процедур `FORTRAN`,
   регистры кадров объемлющих уровней после вызова не восстанавливаются.
 - перед вызовом процедур `FORTRAN` ставится `ржа 6` (а не `ржа 2`), как в программах, оттранслированных компилятором кросс-системы.
 - в режиме `(*=M-*)` умножение целого на константу 2<sup>k</sup> (k > 0, константа – любой из сомножителей) транслируется
   прибавлением `k` к порядку: `ржа 0; слпа 64+k; ржа 7; сл 9(М1)`, без умножения и без константы в пуле
   (так делал компилятор кросс-системы, см. mark3.bin). Результат верен и для отрицательных сомножителей.
 - деление целого на константу 2<sup>k</sup> (`x div 2**k`, при любом режиме `M`) транслируется вычитанием `k` из порядка:
   `вчпа 64+k; сл 9(М1)` (как в pak.bin), а не умножением на обратную константу. Частное округляется вниз и согласовано
   с `x mod 2**k` (маска): `x = (x div 2**k) * 2**k + x mod 2**k`; прежде точное деление отрицательного числа давало
   частное на 1 меньше. `x div 1` больше не дает *NO INTEGER*.
